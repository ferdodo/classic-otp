API Documentation

Classic OTP provides three endpoints for generating, queuing, and validating one-time passwords. Emails are queued and scheduled rather than sent on the spot, so queuing one tells you when it will leave.

POST/otp/reservation

Reserve the next delivery slot before sending an OTP email. The response returns reservationToken, which confirms the slot in /otp, along with scheduledAt and waitSeconds: the instant the email will leave and how long that is from now. Only the latest reservation is valid, so a newer reservation makes earlier tokens unusable and guarantees the promised wait. A token expires after 60 seconds (expiresAt). No request body required.

Response

json
{
  "reservationToken": "reservation-token",
  "scheduledAt": "2026-10-04T14:32:05.000Z",
  "waitSeconds": 3,
  "expiresAt": "2026-10-04T14:33:02.000Z"
}

Examples

curl
curl -X POST https://api.classic-otp.fr/otp/reservation \
  -H "Content-Type: application/json" \
  -d '{}'
javascript
fetch('https://api.classic-otp.fr/otp/reservation', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: '{}'
})
POST/otp

Queue an OTP email into the slot held by a reservation. The reservation token is consumed: it can be used once, and only while it is current and not expired. The response returns scheduledAt, the instant the email will leave, and waitSeconds, how long that is from now. A reservation that was superseded, already used, or expired returns 409.

Request Body

json
{
  "email": "user@example.com",
  "reservationToken": "reservation-token"
}

Response

json
{
  "otpId": "generated-otp-id",
  "scheduledAt": "2026-10-04T14:32:05.000Z",
  "waitSeconds": 3
}

Examples

curl
curl -X POST https://api.classic-otp.fr/otp \
  -H "Content-Type: application/json" \
  -d '{"email":"user@example.com","reservationToken":"reservation-token"}'
javascript
fetch('https://api.classic-otp.fr/otp', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ email: 'user@example.com', reservationToken: 'reservation-token' })
})
POST/otp/:id/challenge

Validate an OTP code for a given OTP ID.

Request Body

json
{
  "code": "123456"
}

Response

json
{
  "valid": true
}

Examples

curl
curl -X POST https://api.classic-otp.fr/otp/otp-id-here/challenge \
  -H "Content-Type: application/json" \
  -d '{"code":"123456"}'
javascript
fetch('https://api.classic-otp.fr/otp/otp-id/challenge', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ code: '123456' })
})
